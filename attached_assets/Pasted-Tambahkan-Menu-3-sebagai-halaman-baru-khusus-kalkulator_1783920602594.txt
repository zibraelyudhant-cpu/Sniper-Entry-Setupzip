=== 1. BUAT FILE BARU ===
artifacts/mobile/app/(tabs)/calculator.tsx

Halaman ini menerima params dari URL:
- entryPrice: number

- takeProfit1: number
- takeProfit2: number
- symbol: string
- direction: 'bullish' | 'bearish'

=== 2. LOGIKA KALKULASI (semua di frontend, tidak ada API call) ===

Formula Binance Futures:

// Ukuran posisi
// Kalau input USDT:
contracts = (modalUsdt * leverage) / entryPrice

// Kalau input contracts/lot:
modalUsdt = (contracts * entryPrice) / leverage

// Initial Margin
initialMargin = (contracts * entryPrice) / leverage

// PnL per level
direction = bias === 'bullish' ? 1 : -1
pnlSL  = contracts * (stopLoss - entryPrice) * direction
pnlTP1 = contracts * (takeProfit1 - entryPrice) * direction
pnlTP2 = contracts * (takeProfit2 - entryPrice) * direction

// ROE%
roeSL  = pnlSL  / initialMargin * 100
roeTP1 = pnlTP1 / initialMargin * 100
roeTP2 = pnlTP2 / initialMargin * 100

// Liquidation Price
// Cross margin:
liqCross = bias === 'bullish'
  ? entryPrice * (1 - 1/leverage)
  : entryPrice * (1 + 1/leverage)

// Isolated margin (maintenance margin rate 0.5%):
mmRate = 0.005
liqIsolated = bias === 'bullish'
  ? entryPrice * (1 - (1/leverage) + mmRate)
  : entryPrice * (1 + (1/leverage) - mmRate)

Warna liq price:
- Hijau: jarak > 20% dari entry (aman)
- Kuning: jarak 10-20% (perhatikan)
- Merah: jarak < 10% (berbahaya)

Format harga: pakai koma sebagai desimal,
tanpa tanda $, presisi mengikuti symbol
(sama dengan fungsi formatPrice yang sudah
ada di sniper.tsx)

=== 6. VALIDASI INPUT ===

- Modal dan leverage harus angka positif
- Leverage minimum 1, maksimum 125
- Kalau input modal USDT berubah → hitung ulang contracts
- Kalau input contracts berubah → hitung ulang modal USDT
- Kalau leverage berubah → hitung ulang semua
- Tampilkan warning kalau leverage > 20x:
