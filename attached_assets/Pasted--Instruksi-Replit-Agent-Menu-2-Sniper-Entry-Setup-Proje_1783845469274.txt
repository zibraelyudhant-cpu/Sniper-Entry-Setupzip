# Instruksi Replit Agent — Menu 2 (Sniper Entry Setup) — Project v2

Ini instruksi untuk membangun Menu 2 dari nol di project baru.
Jangan ambil atau modifikasi kode dari project lama.

---

## KONSEP MENU 2

Menu 2 adalah "Sniper Entry Setup" — analisa mendalam per pair untuk
menghasilkan satu setup entry yang presisi. Pair datang dari hasil
screener Menu 1 (klik nama coin → otomatis buka Menu 2).

Alur analisa top-down:
  D1 + H4  → konfirmasi trend (HH/HL bullish atau LH/LL bearish)
  H1       → cari zona entry terbaik
  15M      → persempit/refine zona dari H1
  5M       → konfirmasi candle untuk timing limit order

---

## NAVIGASI: KLIK COIN DI MENU 1 → MENU 2

Di frontend screener.tsx (Menu 1), setiap card coin harus bisa diklik.
Klik coin → navigasi ke /smc-analysis?symbol=BTCUSDT (atau nama coin).

- Baca query param ?symbol= dari URL

## BACKEND: lib/smc.ts

### STEP 1 — Konfirmasi Trend D1 & H4

Gunakan fungsi analyzePriceActionStructure yang sudah ada di screener.ts.
Fetch klines D1 (limit 60) dan H4 (limit 100).

```typescript
const structD1 = analyzePriceActionStructure(d1.highs, d1.lows, d1.closes);
const structH4 = analyzePriceActionStructure(h4.highs, h4.lows, h4.closes);

// Trend valid kalau D1 dan H4 sama arah dan bukan ranging
if (structD1.bias === 'ranging' || structH4.bias === 'ranging') {
  return { status: 'no_trend', message: 'Struktur D1/H4 ranging, tidak ada trend jelas' };
}
if (structD1.bias !== structH4.bias) {
  return { status: 'no_trend', message: 'D1 dan H4 berbeda arah, trend tidak valid' };
}
const bias = structD1.bias; // 'bullish' | 'bearish'
```

### STEP 2 — Deteksi Zona di H1 (hierarki kekuatan)

Fetch klines H1 (limit 200). Deteksi semua zona lalu pilih yang paling kuat.

Hierarki zona (dari paling kuat ke paling lemah):
1. Unfilled Order dalam OB  → entry di mid Unfilled Order
2. OB + FVG overlap         → entry di mid FVG dalam OB
3. OB + S&R/SnD confluence  → entry di golden zone OB (38.2% dari batas)
4. OB murni                 → entry di golden zone OB (38.2% dari batas)
5. FVG + S&R/SnD confluence → entry di mid FVG
6. FVG murni                → entry di mid FVG
7. S&R/SnD + Fibonacci      → entry tepat di level Fib (WAJIB ada Fib, kalau tidak skip)

Fungsi yang perlu dibangun:

Fetch klines 5M (limit 50). Cek apakah ada candle konfirmasi

### STEP 5 — Hitung SL, TP, dan Timing

```typescript
export function calcSniperLevels(
  entryPrice: number,
  refinedZone: RefinedZone,
  atrH1: number,  // ATR(14) dari H1
  atrH4: number,  // ATR(14) dari H4
  bias: 'bullish' | 'bearish'
): SniperLevels {
  // SL: dari batas zone + buffer ATR H1 × 0.5
  // Untuk BUY: SL = zone_low - (atrH1 * 0.5)
  // Untuk SELL: SL = zone_high + (atrH1 * 0.5)
  // Minimal SL = 1x ATR H1 dari entry (tidak boleh lebih ketat)

  // TP1: R:R 1:1.5 dari entry ke SL
  // TP2: R:R 1:3 dari entry ke SL

  // Setup valid selama: ATR H4 / ATR H1 × 2 jam (perkiraan)
  // Perkiraan hit entry: jarak harga ke entry / ATR H1 per jam
  // Expiry: setup valid selama + 4 jam sebagai buffer
}
```

### STEP 6 — Kondisi Skip (Invalidasi Setup)

Cek setelah zona ditemukan. Kalau salah satu true → return null (skip):

```typescript
export async function checkSkipConditions(
  symbol: string,
  bias: 'bullish' | 'bearish',
  h1Closes: number[], h1Highs: number[], h1Lows: number[],
  h1Volumes: number[], h4Volumes: number[]
): Promise<SkipConditions> {
  // 1. RSI divergence di H1
  //    Bullish divergence bearish (harga HH tapi RSI LH) = skip untuk SELL
  //    Bearish divergence bullish (harga LL tapi RSI HL) = skip untuk BUY

  // 2. Volume + OI tidak mendukung
  //    Volume H1 turun saat harga bergerak searah tren = lemah
  //    OI turun saat harga naik (BUY) atau OI turun saat harga turun (SELL)
  //    = kemungkinan short covering / long liquidation, bukan tren nyata

  // 3. Funding rate ekstrem berlawanan
  //    BUY tapi funding sangat negatif (< -0.1%) = pasar bet turun
  //    SELL tapi funding sangat positif (> 0.1%) = pasar bet naik
  //    Fetch dari: GET /fapi/v1/fundingRate?symbol=X&limit=1
}
```

### Status yang mungkin muncul

**no_trend:**
```
⚠ Tidak Ada Trend Jelas
D1 atau H4 ranging / berbeda arah.
Tidak ada setup entry saat ini untuk [SYMBOL].
```

**no_zone:**
```
⚠ Tidak Ada Zona Valid di H1
Trend valid (D1/H4 bullish) tapi belum ada
OB/FVG/S&R yang cukup kuat di H1.
Tunggu zona terbentuk.
```

**skip_conditions:**
```
⚠ Setup Dilewati
Zona ditemukan tapi ada kondisi yang tidak mendukung:
• RSI divergence terdeteksi di H1
• [atau] Volume + OI tidak mendukung arah
• [atau] Funding rate ekstrem berlawanan (-0.15%)
```
